# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this portfolio, please report it by emailing or opening a private security advisory on GitHub.

**Please do not report security vulnerabilities through public GitHub issues.**

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Security Best Practices

- Never commit sensitive personal information
- Keep dependencies up to date
- Review contact form implementations for proper validation
